# 🍔 Burger Rush

A restaurant management game built with Python and Tkinter, created as a Data Structures and Algorithms project.

## About
Serve customers, manage orders, and keep your restaurant running as the rush gets busier.

## Data structures used
- **Stack:** undo/redo of actions
- **Queue:** customer order flow
- **Priority queue:** VIP customers are served first
- **Hash maps:** quick lookups for menu items and scores
- **Linked list:** order history

## Features
- Combo orders
- High-score table
- Multiple days with an upgrade shop
- Undo and redo
- Order history
- Sound effects
- Random events

## How to run
1. Install Python 3.
2. Download `burger_rush.py`.
3. Run: `python burger_rush.py`
